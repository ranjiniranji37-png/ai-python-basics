# AI Python Basics

Beginner Python programs created as part of the **Codomax Digital Solutions AI & ML Internship - Module 1 (Introduction to AI & Python)**.

## Files

| File | Description |
|------|-------------|
| `variables.py` | Variables, data types and basic operations |
| `loops.py` | for loop, while loop, break and continue |
| `functions.py` | Defining and calling functions |
| `lists.py` | List operations and list comprehension |
| `beginner_program.py` | Student grade calculator mini program |

## How to Run

```bash
python variables.py
python loops.py
python functions.py
python lists.py
python beginner_program.py
```
